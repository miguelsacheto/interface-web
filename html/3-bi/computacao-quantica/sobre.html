Sobre este site


Sobre o projeto

Este site foi desenvolvido como trabalho da disciplina de Interfaces Web, com o objetivo de reunir, de forma organizada, os principais conceitos da computação quântica: o que é, como funciona, quais empresas fabricam os computadores quânticos e quais setores já usam essa tecnologia hoje. É um projeto de estudante, feito para aprender tanto sobre o tema quanto sobre desenvolvimento web com HTML, CSS e Bootstrap.

Sobre os autores

O site foi criado por Miguel Silva Sacheto e Noah Calixto Moi, alunos do 1º D do curso de Interfaces Web. Como citado no aviso desta página, ainda estamos aprendendo, então sugestões, correções e críticas construtivas são sempre bem-vindas — pode entrar em contato pelo GitHub. git do miguel sacheto(clique para ser redirecionado) git do Noah, (clique para ser redirecionado)
