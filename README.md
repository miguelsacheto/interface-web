# 🌐 Interface Web

Repositório dedicado aos projetos práticos de **construção de interfaces web**, desenvolvidos com **HTML** e **CSS**. O conteúdo aqui reúne páginas e estruturas criadas como parte do aprendizado de fundamentos de desenvolvimento front-end e design de interfaces.

## 🎯 Sobre o repositório

Este projeto tem como objetivo praticar e consolidar conhecimentos em:

- Estruturação de páginas web com **HTML5**
- Estilização e layout com **CSS3**
- Boas práticas de design de interface e experiência do usuário
- Fundamentos de design aplicados ao desenvolvimento web

## 🚀 Como visualizar

1. Clone o repositório:
```bash
   git clone https://github.com/miguelsacheto/interface-web.git
```
2. Acesse a pasta `html/`
3. Abra os arquivos `.html` diretamente no navegador de sua preferência
